# 🌍 NGO Portal

A full-stack web application that connects NGOs with volunteers and donors through a simple, secure, and user-friendly platform. The portal helps NGOs manage campaigns, donations, events, and volunteer registrations efficiently.

## 🚀 Features

- 👤 User Authentication (Login & Registration)
- 🏢 NGO Registration and Profile Management
- 💰 Online Donation System
- 🙋 Volunteer Registration
- 📢 Campaign and Event Management
- 📊 Dashboard for NGOs
- 🔍 Search and Filter NGOs
- 📱 Responsive User Interface

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/NGO-Portal.git
```

### Navigate to the project

```bash
cd NGO-Portal
```

### Install dependencies

For backend

```bash
npm install
```

For frontend

```bash
cd client
npm install
```

### Start the backend

```bash
npm start
```

### Start the frontend

```bash
cd client
npm start
```

The application will run at:

- Frontend: `http://localhost:3000`
- Backend: `http://localhost:5000`
